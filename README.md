# Photo Date Fixer

面向本地照片及视频文件的日期分析、规则匹配与时间戳修复桌面软件。

**当前状态：开发预览版（尚未经过完整 Windows 实机验证）。**

## 功能

- Tauri 2 + React + TypeScript + Rust，全部本地处理，无遥测、无需账号。
- 递归扫描照片与视频，默认忽略 `@eaDir`、`Thumbs.db` 等缓存。
- 从文件名及日期目录中识别时间。
- **秒 > 分钟 > 小时 > 天** 的严格精度优先机制；同精度支持规则优先级、冲突检查。
- 图形化规则编辑、筛选、分页、候选结果检查、CSV 导出。
- 只在用户确认后修改文件系统的**最后修改时间**，不修改照片字节、EXIF、文件名。
- 写入本地撤销记录，并在恢复前检查文件是否被其他软件修改。

## 本地开发

安装 Node.js、Rust、Windows C++ Build Tools 和 WebView2 环境，随后执行：

```bash
npm install
npm run tauri dev
```

检查前端：

```bash
npm run build
```

检查 Rust：

```bash
cd src-tauri
cargo test
cargo check
```

打包：

```bash
npm run tauri build
```

## 使用说明

1. 扫描工作台选择媒体目录，点击扫描。
2. 在「匹配规则」配置文件名/目录名正则表达式及解析日期格式，保存后重新匹配。
3. 在「匹配结果」查看预期日期和所有候选。默认优先秒级、其次分钟、小时、天级。
4. 冲突与未匹配文件不会自动修复；执行前确认列表及规则。
5. 点击修复并确认。历史记录支持撤销原来的最后修改时间。

如果文件内部已有 EXIF 拍摄时间，Synology Photos 可能优先使用 EXIF；仅修改文件时间不会覆盖 EXIF。

## 当前限制 / 后续工作

- v0.1 仅提供文件名和目录日期规则，**ExifTool 元数据分析尚未集成**；有 EXIF 的文件需先确认照片管理器实际使用的时间。
- 目前未提供手动修改单文件日期、单独解决冲突或规则测试沙盒。
- 执行修复与撤销为同步后台设计中的初版，批量操作性能、取消和异常恢复仍需测试。
- 扫描结果保存在运行进程内；退出软件后需要重新扫描。
- 网络共享目录、时区转换及 Windows 安装包需要实机验证。
- 因为仍处于预览阶段，建议先在少量**复制出来的测试文件**上验证。

## 隐私与开源

应用不上传文件、扫描记录或网络/设备信息。用户选定的目录、绝对文件路径和操作记录只在运行时内存或本机应用数据目录中使用，**不会写入源代码仓库**。CSV 只在用户明确导出时保存到用户选择的位置。

禁止提交：真实照片、真实扫描报告、原始路径、操作记录、环境诊断信息、设备资料、密钥、令牌和任何可以识别使用者的信息。

`.gitignore` 忽略常见缓存与日志，但在公开仓库之前仍应人工检查 Git 提交历史。
